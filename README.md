# Expense Bot

Telegram-бот для учёта ежедневных расходов по категориям.

## Возможности
- ввод расхода кнопками: категория, затем сумма
- /today: отчёт за сегодня
- /week: отчёт за 7 дней
- данные хранятся в SQLite

## Запуск
1. pip install aiogram
2. export BOT_TOKEN=токен_от_BotFather
3. python bot.py

Стек: Python, aiogram 3, SQLite.
